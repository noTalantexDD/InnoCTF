# База/логика
Логический порядок обработки sql-запроса:
1. FROM и JOIN — откуда берём данные?
2. WHERE — какие строки выкидываем из таблицы с прошлого шага?
3. GROUP BY — как схлопываем оставшиеся строки в группы?
4. HAVING — какие группы выкидываем?
5. SELECT — что показываем в итоге?
6. ORDER BY — как отсортировать то, что показываем?
7. LIMIT — сколько отобразить?
Типы запросов: SELECT, INSERT, UPDATE, DELETE
Ограничение запроса для атак: # / -- / --- / ;

# Несколько запросов и склеивание
UNION - добавление результатов одного запроса к другому (объединяет в единый вертикальный список)
```sql
SELECT column1, column2 FROM table1
UNION
SELECT column1, column2 FROM table2;
```


Подзапросы - это SELECT-запросы внутри другого SQL-запроса, записанный в круглых скобках
```sql
SELECT name, salary 
FROM employees
WHERE salary > (SELECT AVG(salary) FROM employees);
```
- Скалярный — возвращает ровно 1 значение (1 строку и 1 столбец). Подходит для операторов =, >, <, >=, <=.
- Одностолбцовый (список значений) — возвращает набор значений из одного столбца. Используется с IN, NOT IN, ANY, ALL.
- Табличный — возвращает несколько строк и столбцов (временную таблицу). Чаще ставится в FROM (обязательно с псевдонимом).
- Коррелированный — ссылается на столбцы внешнего запроса и пересчитывается для каждой его строки. Часто применяется с EXISTS и NOT EXISTS

Ограничение и несколько запросов через ;

# Синтаксис
SELECT → FROM → JOIN → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT

```sql
SELECT column1, column2 AS alias_name
FROM main_table
JOIN other_table ON main_table.id = other_table.main_id --объединяет по условию 
WHERE condition
GROUP BY column1 --группирует строки по стообцу
HAVING aggregate_condition --фильтрует группы после GROUP BY по каким-то условиям или фильтрует по агрегатным условиям (COUNT, SUM, AVG, MIN, MAX)
ORDER BY column1 DESC --сортирует результат по возрастанию (ASC, по умолчанию) или убыванию (DESC)
LIMIT 10;
```
GROUP BY - объединяет строки с одинаковыми значениями в указанных столбцах в единые сводные строки. Обычно он используется вместе с агрегатными функциями, чтобы вычислять итоговые показатели для каждой группы данных.

Под «агрегатными условиями» в SQL понимают фильтрацию сгруппированных данных через HAVING или условную агрегацию (подсчёт метрик только для строк, подходящих под условие)

Условная агрегация: 
```sql
SUM(CASE WHEN status = 'active' THEN 1 ELSE 0 END) AS active_count_all,
```
