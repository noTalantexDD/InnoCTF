# методы, изображение

В любом изображении каждый пиксель представляет собой набор чисел, которые описывают его цвет. Эти числа состоят из RGB (красный, зелёный и синий), и каждый цвет в пикселе представлен числом от 0 до 255 (или 8 бит на каждый канал)
1) метод LSB работает следующим образом: чтобы скрыть сообщение, мы изменяем наименее значимые биты каждого цвета в пикселе. Наименее значимый бит — это самый правый бит в числе. Например, если у нас есть число 123 (в двоичной системе: 01111011), то наименее значимый бит — это последний 1 в конце числа
2) RARJPEG — это техника стеганографии, в которой скрытая информация (например, текст или файлы) внедряется в JPEG-изображение, сжимаемое в RAR-архив. Создание такого контейнера позволяет скрыть данные внутри изображения, при этом файл сохраняет свою функциональность как изображение, а сам файл выглядит как обычный JPEG, не вызывая подозрений.

# методы, текст
1) Невидимые пробелы и знаки: В любом текстовом редакторе (например, в Microsoft Word) существуют символы, которые по сути не имеют визуального отображения, но являются частью текста. К таким символам относятся:
- Невидимый пробел (например, Unicode-символ U+200B "Zero Width Space" или U+200C "Zero Width Non-Joiner").
- Невидимые табуляции и пробелы.
- Невидимые знаки переноса строки.
1) Ещё один метод скрытия информации в текстовых документах — это использование различных шрифтов.
# методы, аудио 
1) В стеганографии с использованием амплитудной модуляции скрытая информация внедряется в звуковой файл путем изменения амплитуды отдельных звуковых волн в файле
- Секретные данные (например, бинарный код) преобразуются в электрический сигнал, который будет модулировать несущее колебание
- амплитудная манипуляция (ASK — Amplitude Shift Keying), где разные уровни амплитуды соответствуют разным битам сообщения. 
- Изменяем амплитуду каждой волны в аудиофайле согласно двоичному представлению каждого символа. Для каждого бита (0 или 1) в сообщении мы увеличиваем или уменьшаем амплитуду на очень малую величину.
- с помощью демодуляции (например, детектора огибающей) из полученного сигнала извлекается исходный модулирующий сигнал

# стегоанализ
1) Анализ на основе статистики
Один из самых распространённых методов стеганоанализа — это статистический анализ данных. Этот подход фокусируется на поиске аномалий в структуре файла, которые могут свидетельствовать о скрытых данных.
- Частота изменения пикселей.
- Сравнение распределения цветов.
- Нерегулярности в блоках пикселей.
2) Анализ с использованием машинного обучения
3) Прямой анализ изменений в контенте
4) Аномалии в размере файла
5) Сетевой анализ. Когда стеганография используется для скрытой передачи данных через сеть (например, через DNS-запросы или пакеты в интернете)
6) Каждый файл популярного формата (PNG, JPEG, ZIP, PDF) начинается со строго определенных байтов (заголовка), которые подсказывают операционной системе, как его открывать. Утилита file в Linux считывает именно их.
