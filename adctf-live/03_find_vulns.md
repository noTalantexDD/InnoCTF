# Как искать уязвимости (шаблоны)

Цель — найти место, где можно вытащить чужой флаг (обычно: достать приватные данные без прав).

## 1. Скопировать исходники
```bash
scp -r ubuntu@<сервак>:/opt/service1 ./service1 && cd service1
```
Язык по файлам: .py Python, .js/.ts Node, .go Go, .php PHP.

## 2. Греп по опасному
```bash
grep -rniE "exec|eval|system|popen|subprocess|pickle|yaml.load" .
grep -rniE "secret|token|password|admin|debug|backdoor" .
grep -rniE "select .*\+|format\(|execute\(" .
grep -rniE "open\(|\.\./|os.path.join" .
```

## 3. Классы уязвимостей
- **IDOR (нет проверки прав):** `/note/<id>` отдаёт чужую заметку без проверки владельца. Самое частое.
- **Path traversal:** `?name=../../..` — чтение чужих файлов.
- **SQL/NoSQL инъекция:** параметр в запрос без экранирования.
- **Предсказуемые id/токены:** подделываешь.
- **Командная инъекция:** ввод в os.system.
- **Десериализация:** pickle.loads(ввод).
- **debug/admin-ручки** без пароля.

## 4. Где флаг
Смотри, куда чекер кладёт флаг (ручка «создать»/«прочитать по id»). Флаг там, куда указывает flag_id из attack_data.

## 5. Проверить руками
```bash
curl -s "http://<IP_жертвы>:5000/note/<flag_id>"
```
Увидел флаг без авторизации → это уязвимость. Пиши эксплойт (04_exploit.md), зови Пашу.
