# Паша — Патчер (личный гайд с нуля)

Ты читаешь исходники наших сервисов на серваке и чинишь дыры. Читай ../05_patch.md и ../03_find_vulns.md.

## Что скачать (на своей Kali)
```bash
sudo apt install -y python3-pip git
pip3 install requests
```
Работаешь в основном на серваке по SSH (`ssh ubuntu@<сервак>`).

## Главное правило
Чини **маленьким диффом** и НЕ ломай работу сервиса. После каждого патча — чекер зелёный. Красный чекер хуже самой дыры.

## Шаги
- [ ] 10:40 — вместе с Глебом читаете код, ищете баги
- [ ] каждый сервис под git:
```bash
cd /opt/service1 && git init -q && git add -A && git commit -qm round0
# после патча:
git add -A && git commit -m "patch: закрыл <что>"
```
- [ ] патчишь дыру (примеры по классам — ../05_patch.md)
- [ ] перезапуск: `sudo systemctl restart <сервис>`
- [ ] проверяешь: сервис отвечает? чекер зелёный? (спроси Сашу А)
- [ ] берёшь дыры от Саши Ф и Глеба — закрываешь ПЕРВЫМИ

## Если сломал
`git reset --hard round0 && sudo systemctl restart <сервис>`
