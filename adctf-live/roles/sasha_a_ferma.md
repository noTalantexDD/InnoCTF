# Саша А — Фермер/Сабмит + SLA-вотчер (личный гайд с нуля)

Твоя роль простая, но без неё команда не наберёт очки. Ты — «диспетчер»: держишь ферму, следишь за флагами и сервисами.

## Что скачать/поставить (СЕГОДНЯ, с интернетом)
```bash
sudo apt install -y python3-pip git tmux curl jq
pip3 install requests flask
git clone https://github.com/DestructiveVoice/DestructiveFarm
```
Прочитай [../farm/README.md](../farm/README.md) и [../00_how_it_works.md](../00_how_it_works.md).

## Твоя задача по шагам (10:00–10:40)
1. На своей Kali поднять ферму (в tmux, чтобы не умерла): `../farm/README.md`.
2. Узнать у оргов / на /serp: адрес сабмита (host:port), **team token**, адрес attack_data. Вписать в конфиг фермы.
3. Открыть веб-морду фермы в браузере (обычно `http://127.0.0.1:5000`).

## Во время игры (твой цикл, повторяй всю игру)
- [ ] Смотришь веб-морду фермы: флаги должны идти со статусом ACCEPTED. Если пошли INVALID/ошибки — кричишь Глебу и смотришь конфиг.
- [ ] Смотришь скорборд/SLA. Какой наш сервис покраснел → сразу говоришь Роме и Паше (какой именно).
- [ ] Тянешь attack_data каждый раунд (`../scripts/attack_data.py`), проверяешь что цели свежие.
- [ ] Запускаешь готовые сплойты Глеба через ферму по всем командам.

## Если что-то пошло не так
- Флаги «too old/expired» — норма, это старые; главное что свежие ACCEPTED.
- Ферма упала — перезапусти в tmux. Запасной сабмиттер: `../scripts/submit_min.py`.
- Не знаешь токен/адрес — спроси оргов или смотри /serp.
